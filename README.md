## ⚙️ In-App Update Source Configuration

AnyFetch has a built-in release updater. By default, it checks the official repository for updates. If you are using a custom fork or want to point to this repository manually:

1. Open **AnyFetch** on your phone.
2. Tap the **Settings (⚙️)** tab.
3. Under the **Updates** card, tap **Source Repository** to expand the setting.
4. Enter the GitHub repository in either format:
   ```text
   AbhishekS04/anyfetch-expo
   ```
   *or*
   ```text
   https://github.com/AbhishekS04/anyfetch-expo
   ```
5. Tap **Apply**.
6. The app will immediately check for the newest APK release and notify you with a single tap to update!

## 📖 How to Use

1. **Copy Link**: From any app (Instagram, Pinterest, X/Twitter), tap **Share** ➔ **Copy Link**.
2. **Open AnyFetch**: The app automatically detects clipboard links or you can paste the URL into the input field.
3. **Fetch & Download**: Tap **Fetch Media** to preview the media, then tap **Download** to save it directly to your device.
