# Implementation Plan — Self-Hosted OTA Updates

Implement local, self-hosted Over-the-Air (OTA) updates using `expo-updates` without any external cloud service or subscription costs.

## Proposed Changes

### 1. Dependencies & App Config

- Install `expo-updates` library using `npx expo install`.
- Rename or create `app.config.js` to dynamically wrap `app.json` and inject `updates.url` using the `UPDATES_URL` environment variable.

#### [NEW] [app.config.js](file:///run/media/abhishek/BBC/repos/anyfetch-expo/app.config.js)

Define dynamic configurations, mapping the update URL to the local system IP:

```javascript
module.exports = ({ config }) => {
  return {
    ...config,
    updates: {
      url: process.env.UPDATES_URL || "http://127.0.0.1:4000/api/manifest",
      enabled: true,
      checkAutomatically: "NEVER" // Allow user manual check trigger in settings
    }
  };
};
```

#### [MODIFY] [package.json](file:///run/media/abhishek/BBC/repos/anyfetch-expo/package.json)

Add scripts for exporting updates, running the updates server, and building locally:

- `"serve-updates": "node scripts/serve-updates.js"`
- `"export-updates": "npx expo export"`

---

### 2. Update Server Implementation

Create a custom, zero-dependency Node.js script to run the updates server locally. This server parses `dist/metadata.json` generated by Metro, computes SHA-256 hashes of bundles and assets, and serves the files under the Expo Updates Protocol V1.

#### [NEW] [serve-updates.js](file:///run/media/abhishek/BBC/repos/anyfetch-expo/scripts/serve-updates.js)

A lightweight HTTP server implementing the updates protocol.

---

### 3. Application Settings Screen UI

Modify `SettingsScreen.tsx` to include an "APP UPDATES" section with manual update checks and feedback alerts.

#### [MODIFY] [SettingsScreen.tsx](file:///run/media/abhishek/BBC/repos/anyfetch-expo/src/screens/SettingsScreen.tsx)

- Import `* as Updates from 'expo-updates'`.
- Implement `handleCheckForUpdates` logic using `Updates.checkForUpdateAsync()`, `Updates.fetchUpdateAsync()`, and `Updates.reloadAsync()`.
- Add the UI elements with styling consistent with the existing dark theme and orange accents (`#FF9F0A`).

---

### 4. Native Android Prebuild

- Run `npx expo prebuild --platform android` to create/update the `/android` directory, incorporating the `expo-updates` library.

## Verification Plan

### Automated Tests

Verify server starts up and outputs a valid JSON manifest:

```bash
# 1. Run local build export
npm run export-updates
# 2. Run updates server
npm run serve-updates
# 3. Request manifest using curl with headers
curl -H "expo-protocol-version: 1" -H "expo-platform: android" http://localhost:4000/api/manifest
```

### Manual Verification

1. Run local development build using `npx expo run:android` to compile native code.
2. Edit a screen (e.g. modify a text string in `HomeScreen.tsx`).
3. Run `npm run export-updates` and export OTA files.
4. Go to settings in the app, press the "Check for Updates" button, and confirm it installs the update and restarts.
