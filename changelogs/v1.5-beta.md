# AnyFetch v1.5-beta (Beta)

Universal, 100% on-device private media downloader by **Abhishek Singh** ([@AbhishekS04](https://github.com/AbhishekS04)).

---

### 🥷 Dynamic Mascot App Icon & Duolingo-Style Inactivity Engine
- **Runner Ninja Main Launcher Icon**: Official AnyFetch Runner Ninja mascot (`mainlogo.png`) is now the default launcher icon across the home screen, app drawer, and system shortcuts, fully compliant with Android adaptive-icon safe-zone guidelines (66dp circle/squircle bounds).
- **Automated Streak & Inactivity Switching**: Dynamic launcher icon transforms based on user engagement habits:
  - **Active / In Use**: Runner Ninja (`mainlogo.png`)
  - **24 Hours Inactive**: Sad Crying Ninja (`sadlogo.png`)
  - **48 Hours Inactive**: Fiery Angry Ninja (`angrylogo.png`)
  - **72+ Hours Inactive**: Requesting / Pleading Ninja (`dramaticlogo.png`)
- **Native Android Architecture**: Implemented via native `<activity-alias>` entries, `AlarmManager.setAndAllowWhileIdle()`, and `RECEIVE_BOOT_COMPLETED` broadcast receiver. The base `MainActivity` remains permanently enabled to prevent `ActivityNotFoundException` across Android 10 through 15.
- **Instant Active Restoration**: Opening the app or bringing it to the foreground immediately restores the Runner Ninja icon and rearms inactivity timers.
- **100% Autonomous**: Removed manual mascot toggles from Settings; companion reactions now dynamically mirror real user engagement.

---

### ✨ Full-Screen "What's New" Experience
- **Dedicated Release Highlights Screen**: Replaces the old popup modal with an immersive, full-screen What's New showcase when updating to major or milestone versions.
- **Cold-Start Splash Gate**: Synchronous pre-render gate keeps the native Android splash screen visible until version status resolves, guaranteeing 0ms flicker or flash of the home screen.
- **Hold-to-Continue Interaction**: Haptic-rich hold-to-continue button with dynamic progress fill, spring-back cancellation, single-fire lockouts, and full TalkBack/accessibility action support.
- **Hardware Back Interception**: Safely intercepts Android back gestures on first launch to ensure the onboarding release highlights are cleanly reviewed and acknowledged.
- **Downgrade & Persistence Shield**: AsyncStorage persistence tracks `anyfetch.lastAcknowledgedReleaseVersion` with semver comparison to ensure the screen displays exactly once per major release.

---

### 🎨 UI/UX & Navigation Architecture
- **Floating Header Navigation**: Clean header quick-access menu for `Downloads`, `History`, `Theme Studio`, and `About Us`.
- **Dedicated About & Architecture Hub**: In-depth page detailing 100% on-device processing, privacy guarantees, technical specifications, and interactive developer showcase cards.
- **Streamlined 4-Tab Fluid Dock**: Bottom navigation bar refined to 4 core tabs (`Home`, `Downloads`, `History`, `Settings`) with expanded touch geometry and responsive spring physics.
- **Unified Brand Identity**: All legacy abstract placeholder artwork removed; all in-app modals, update prompts, and headers now feature authentic AnyFetch mascots.
