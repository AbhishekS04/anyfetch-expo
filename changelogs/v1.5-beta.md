# AnyFetch v1.5-beta (Beta)

### ✨ What's New & Refinements
- **Redesigned Floating Navbar**: Clean, modern menu labels for immediate navigation (`Downloads`, `History`, `Theme Studio`).
- **Direct About Us Access**: Integrated dedicated `About Us` entry into the floating header for instant access to privacy policies, open-source info, and specifications.
- **Streamlined 4-Tab Fluid Dock**: Bottom navigation bar refined to 4 core tabs (`Home`, `Downloads`, `History`, `Settings`) with expanded touch geometry and smoother spring physics.
- **Dynamic Welcome Experience**: Introducing a one-time welcome experience screen celebrating new version features upon update.
- **Custom Update Interface**: Polished in-app updater card featuring the authentic AnyFetch brand icon, beta release indicators, and direct APK installation.

### 🧪 Beta Notes
- This is a pre-release beta build for testing navigation updates and on-device stability.
