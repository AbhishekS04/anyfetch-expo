# AnyFetch v1.1.1

### 🔒 Security & System Stability
- **Android Intent Security Hardening**: Upgraded in-app APK installer to use combined Intent flags `FLAG_ACTIVITY_NEW_TASK` (`268435456`) and `FLAG_GRANT_READ_URI_PERMISSION` (`1`). This prevents installer crashes, URI access denials, and task collisions across Android 11 through 15.
- **Package Integrity Verification**: Added download integrity validation ensuring downloaded APK files are verified (`size >= 1MB`) before triggering the Android Package Installer. Truncated or corrupted downloads are automatically rejected and cleared.
- **Native OS Version Introspection**: Integrated `expo-application` to query the true runtime `versionName` directly from Android OS `PackageManager`. Eliminates bundle cache version desyncs and permanently fixes infinite update loops.

### ⚡ Build & Release Pipeline
- **Deterministic Clean Builds**: Configured `./gradlew clean assembleRelease` and automatic cache purging in build automation, ensuring Hermes bytecode and React Native assets are compiled 100% fresh on every release.
- **Automated Changelog System**: Every build and release now automatically references version notes in `changelogs/` and synchronizes release notes directly to GitHub Releases and the in-app update modal.

### 🛠️ Bug Fixes
- Resolved issue where updating to a new release caused the app to repeatedly prompt for an update after installation.
- Fixed update availability checks to ensure an APK binary is attached before prompting users.
